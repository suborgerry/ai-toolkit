# Figma Pixel Perfect Frontend Skill

Recommended Codex/agent path: `.codex/skills/figma-pixel-perfect-frontend/`

Use this skill when converting Figma designs, screenshots, mockups, or visual references into production-ready frontend markup.

Use it for:

- Figma to HTML
- Screenshot to HTML
- Responsive frontend sections
- CMS-ready static markup
- Pixel-focused frontend implementation
- Visual QA and browser screenshot comparison

The skill prioritizes project conventions, clean markup, accessibility, responsive behavior, local assets, and verified visual accuracy.

It does not create WordPress, PHP, or ACF implementations unless the user explicitly asks for that.
