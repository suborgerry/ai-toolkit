# ACF WP Flexible Content Skill

Recommended Codex/agent path: `.codex/skills/acf-wp-flexible-content/`

Use this skill when converting completed frontend markup into WordPress ACF Flexible Content sections.

Use it for:

- HTML to ACF Flexible Content
- WordPress PHP section templates
- ACF Local JSON layouts
- Flexible section naming
- ACF field modeling
- Theme Settings / Options Page fields
- Header, footer, and navigation integration when needed

The skill prioritizes existing project conventions, clean ACF structure, safe PHP output, reusable layouts, correct escaping, and minimal surgical changes.

It does not recreate frontend design from scratch unless the user explicitly asks for that.
